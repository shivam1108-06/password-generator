# Password Generator 🔐

A modern Password Generator built using Flask, Python, Bootstrap 5, and JavaScript.

## Features

* Generate Secure Passwords
* Custom Password Length
* Uppercase Letters Option
* Numbers Option
* Symbols Option
* Copy Password Button
* Password Strength Indicator
* Password History
* Loading Animation
* Real-Time Date & Time
* Responsive Design

## Technologies Used

* Python
* Flask
* HTML5
* CSS3
* Bootstrap 5
* JavaScript

## Installation

Clone Repository

```bash
git clone https://github.com/shivam1108-06/password-generator.git
```

Move to Project Folder

```bash
cd password-generator
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run Application

```bash
python app.py
```

Open Browser

```text
http://127.0.0.1:5000
```
